# Team 4 - pre-event preparation

Prepared on 28 Oct 2026, before the European AI Challenge. **It contains no challenge data and no results.**

| Folder | What it is |
|---|---|
| `template/` | Blank policy tool: a map + panel web page. It builds to one HTML file (`dist/policy-tool.html`) for the email deliverable and an Android app for the live demo. See `template/README.md`. |
| `patterns/` | Generic, tested GIS helper functions (`patterns.py`, tests in `test_patterns.py`) and a demo notebook. |

Disclosure for the AI sheet: see `template/TEMPLATE-NOTE.md`.

Run the template locally: `cd template/web && python3 -m http.server 8000`, then open http://127.0.0.1:8000.
